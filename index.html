নিচের লজিক সার্কিটটির আউটপুট (Y) কোন গেইটের সমতুল্য? Which logic gate is equivalent to the output (Y) of the circuit below?
ব্যাখ্যা (সঠিক উত্তর: খ — AND Gate): Explanation (Correct Answer: B — AND Gate):
প্রথম গেইটটি একটি NAND গেইট যার আউটপুট (A·B)'। এরপর এটি একটি NOT গেইটের মধ্য দিয়ে যাওয়ায় ডাবল কমপ্লিমেন্ট হয়ে আউটপুট Y = ((A·B)')' = A·B হয়, যা AND Gate-এর সমতুল্য। The first gate is a NAND gate producing (A·B)'. Passing through the subsequent NOT gate applies double negation Y = ((A·B)')' = A·B, which is an AND Gate.
