সহজ ভাষায় ওয়েব পেজ কীভাবে তৈরি হয়?

একটি মানুষের শরীরের সাথে ওয়েবসাইটের তুলনা (HTML + CSS + JavaScript)

৩.১

HTML কী? এর কাজ ও উদ্দেশ্য (Definition, Tasks & Purpose)

HTML-এর সংজ্ঞা (Definition)

HTML-এর পূর্ণরূপ হলো HyperText Markup Language। এটি কোনো প্রোগ্রামিং ল্যাঙ্গুয়েজ (Programming Language) নয়, বরং এটি একটি Markup Language যা ওয়েব পেজ তৈরি ও তার কাঠামো (Structure) নির্ধারণ করার জন্য ব্যবহৃত হয়। ১৯৯১ সালে Tim Berners-Lee এটি উদ্ভাবন করেন।

HyperText কী?

এমন লেখা যার ভেতরে লিংক (Link) থাকে। এই লিংকে ক্লিক করলে এক ওয়েব পেজ থেকে অন্য ওয়েব পেজে যাওয়া যায়।

Markup Language কী?

যে ভাষায় বিভিন্ন Tag (যেমন: <h1>, <p>) ব্যবহার করে ওয়েব ব্রাউজারকে বলে দেওয়া হয় কোন লেখাটি কেমন দেখাবে।

HTML-এর প্রধান কাজ (Tasks)

  • ওয়েব পেজের মূল কাঠামো (Structure) তৈরি করা।
  • হেডিং (Heading), প্যারাগ্রাফ (Paragraph), লিস্ট (List) ও টেবিল (Table) সাজানো।
  • ছবি (Image), অডিও (Audio) এবং ভিডিও (Video) যুক্ত করা।
  • হাইপারলিংক (Hyperlink) তৈরি করে একাধিক পেজ সংযুক্ত করা।
  • ইউজার থেকে তথ্য নেওয়ার জন্য ফর্ম (Form) ও বাটন তৈরি করা।

HTML-এর উদ্দেশ্য (Purpose)

  • Browser-কে নির্দেশনা দেওয়া: Chrome, Firefox বা Edge ব্রাউজার HTML পড়ে তা মানুষের দেখার উপযোগী ওয়েব পেজে রূপান্তর করে।
  • সর্বজনীনতা (Platform Independent): Windows, Mac, Linux বা মোবাইল—সব ডিভাইসেই HTML একইভাবে কাজ করে।
  • তথ্য শেয়ারিং: সারা বিশ্বের মানুষ যেন ইন্টারনেটের মাধ্যমে সহজেই তথ্য পড়তে ও শেয়ার করতে পারে।

HTML Element এবং Attribute-এর গঠন (Anatomy)

একটি সম্পূর্ণ HTML Element সাধারণত একটি Start Tag, তার ভেতরের Content, এবং একটি End Tag নিয়ে গঠিত হয়। আর Start Tag-এর ভেতরে অতিরিক্ত তথ্য যোগ করতে Attribute ব্যবহার করা হয়।

একটি বেসিক HTML পেজের গঠন (Basic Structure) 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>স্বাগতম!</h1>
    <p>এটি আমার প্রথম HTML পেজ।</p>
  </body>
</html>

প্রতিটি লাইনের ব্যাখ্যা:

<!DOCTYPE html> — ব্রাউজারকে বলে দেয় এটি একটি HTML5 ডকুমেন্ট।
<html> — পুরো HTML পেজের মূল বা Root Element।
<head> — পেজের গোপন তথ্য (Meta data, Title, CSS Style) এখানে থাকে।
<body> — ব্রাউজারের মূল স্ক্রিনে যা দেখা যায় (লেখা, ছবি, টেবিল) সব এর ভেতর থাকে।
৩.২

CSS কী? এবং এর উদ্দেশ্য কী? (What is CSS & Purposes)

CSS-এর পূর্ণরূপ হলো Cascading Style Sheets। HTML দিয়ে তৈরি করা সাধারণ ওয়েব পেজকে সুন্দর, রঙিন, আকর্ষণীয় এবং আধুনিক রূপ (Design & Layout) দেওয়ার জন্য CSS ব্যবহার করা হয়।

CSS ব্যবহারের মূল উদ্দেশ্যসমূহ (Purposes of CSS):

সৌন্দর্যবর্ধন (Styling)

ব্যাকগ্রাউন্ড কালার, টেক্সট কালার, ফন্ট, বর্ডার ও শ্যাডো যোগ করে পেজকে সুন্দর করা।

সময় সাশ্রয় (Saves Time)

একটি External CSS ফাইল দিয়ে একটি ওয়েবসাইটের শত শত পেজের ডিজাইন একবারে নিয়ন্ত্রণ করা যায়।

রেসপনসিভ ডিজাইন

মোবাইল, ট্যাবলেট এবং কম্পিউটারের স্ক্রিন অনুযায়ী পেজের লেআউট সুন্দরভাবে মানিয়ে নেওয়া।

কোড আলাদা রাখা

HTML (কনটেন্ট) এবং CSS (ডিজাইন) আলাদা থাকলে কোড পড়া ও পরিবর্তন করা অনেক সহজ হয়।

৩.৩

CSS-এর প্রকারভেদ (Types of CSS with Examples)

একটি HTML ওয়েব পেজে ৩ উপায়ে (3 Types) CSS যুক্ত করা যায়। নিচে একের পর এক প্রতিটি প্রকারের বিস্তারিত ব্যাখ্যা ও উদাহরণ দেওয়া হলো:

১

Inline CSS (ইনলাইন সিএসএস)

যখন কোনো নির্দিষ্ট একটি HTML ট্যাগের ভেতরে সরাসরি style অ্যাট্রিবিউট ব্যবহার করে ডিজাইন দেওয়া হয়, তাকে Inline CSS বলে। এটি শুধু ওই একটি এলিমেন্টের ওপরই কাজ করে। 

<h1 style="color: white; background-color: tomato; text-align: center;">
  University of Dhaka
</h1>
<p style="color: red; font-weight: bold;">
  এটি একটি লাল রঙের প্যারাগ্রাফ।
</p>
আউটপুট:
University of Dhaka

এটি একটি লাল রঙের প্যারাগ্রাফ।

২

Internal CSS (ইন্টারনাল সিএসএস)

যখন HTML পেজের <head> অংশের ভেতরে <style> ... </style> ট্যাগ ব্যবহার করে CSS লেখা হয়, তাকে Internal CSS বলে। এটি সম্পূর্ণ একটি HTML পেজের জন্য কাজ করে। 

<!DOCTYPE html>
<html>
<head>
  <style>
    body { background-color: powderblue; }
    table, th, td { border: 1px solid black; }
  </style>
</head>
<body>
  <p>এই পুরো পেজের ব্যাকগ্রাউন্ড হালকা নীল হবে।</p>
</body>
</html>

শিক্ষকের দেওয়া index.htm ফাইলে টেবিলের বর্ডার দেওয়ার জন্য এই Internal CSS ব্যবহার করা হয়েছে।

৩

External CSS (এক্সটারনাল সিএসএস)

যখন সমস্ত CSS কোড আলাদা একটি .css ফাইলে (যেমন: style.css) সেভ করে HTML-এর <head> অংশে <link> ট্যাগ দিয়ে যুক্ত করা হয়, তাকে External CSS বলে। বড় ওয়েবসাইটের জন্য এটি সবচেয়ে সেরা পদ্ধতি।

index.html ফাইল: 
<head>
  <link rel="stylesheet" href="style.css">
</head>
style.css ফাইল: 
body {
  background-color: #f8fafc;
}
h1 {
  color: navy;
}

অগ্রাধিকার বা CSS Priority (গণিতের ভাষায় Specificity)

একই এলিমেন্টে যদি একাধিক CSS দেওয়া হয়, তবে ব্রাউজার নিচের ক্রম অনুযায়ী অগ্রাধিকার (Priority) দেয়:

$$\text{Inline CSS } (1,0,0,0) > \text{ID Selector } (0,1,0,0) > \text{Class Selector } (0,0,1,0) > \text{Tag Selector } (0,0,0,1)$$

অর্থাৎ, Inline CSS-এর ক্ষমতা সবচেয়ে বেশি, এরপর Internal / External CSS (যেটি পরে লেখা হবে সেটি কাজ করবে)।

৩.৪

বিভিন্ন HTML ট্যাগের কাজ ও ফরম্যাটিং

প্রতিটি কার্ডে ৩টি অংশ: ১) বিস্তারিত ও ফরম্যাট, ২) সম্পূর্ণ HTML কোডে ব্যবহার, ৩) লাইভ আউটপুট

HTML Comments (কমেন্ট)

কোডের ভেতরে নিজের বোঝার জন্য কোনো নোট লিখে রাখতে বা কোনো কোড সাময়িকভাবে বন্ধ (Disable) রাখতে কমেন্ট ব্যবহার করা হয়। ব্রাউজার কমেন্টগুলো স্ক্রিনে দেখায় না। 

<!-- এটি একটি HTML কমেন্ট, ব্রাউজারে দেখাবে না -->
<!-- <p>এই প্যারাগ্রাফটি লুকানো আছে</p> -->

Quotations ও বিশেষ ট্যাগ

  • <blockquote> — অন্য উৎস থেকে নেওয়া বড় উদ্ধৃতি (Indentation সহ)।
  • <q> — ছোট উদ্ধৃতি (স্বয়ংক্রিয়ভাবে " " চিহ্ন বসে)।
  • <address> — লেখক বা প্রতিষ্ঠানের ঠিকানা (Italic ফন্টে দেখায়)।
  • <details> & <summary> — ক্লিক করলে খোলে ও বন্ধ হয় এমন ড্রপডাউন তথ্য।
মিডিয়া ও কালার

HTML Colors, Links এবং Images

HTML Colors (রঙের গণিত ও লাইভ মিক্সার)

HTML-এ রঙ মূলত ৩ ভাবে লেখা যায়: Color Name (যেমন: tomato, powderblue), RGB, এবং HEX কোড। প্রতিটি চ্যানেলে (Red, Green, Blue) $0$ থেকে $255$ পর্যন্ত মোট $256$টি মান থাকে। তাই মোট সম্ভাব্য রঙের সংখ্যা:

$$\text{Total Colors} = 256 \times 256 \times 256 = 2^{24} = 16,777,216 \text{ (প্রায় ১ কোটি ৬৭ লক্ষ রঙ!)}$$
Red (R) 255
Green (G) 99
Blue (B) 71
rgb(255, 99, 71) #FF6347 (Tomato)

HTML Links (<a> ট্যাগ)

এক পেজ থেকে অন্য পেজে যাওয়ার জন্য Anchor Tag (<a>) ব্যবহৃত হয়। এর সবচেয়ে গুরুত্বপূর্ণ অ্যাট্রিবিউট হলো href (Hypertext Reference)। 

<a href="https://www.du.ac.bd/" target="_blank">
  Visit Dhaka University
</a>

টিপস: target="_blank" দিলে লিংকটি নতুন ট্যাবে (New Tab) ওপেন হয়।

HTML Images (<img> ট্যাগ)

ওয়েব পেজে ছবি দেখানোর জন্য <img> ট্যাগ ব্যবহৃত হয়। এটি একটি Empty Tag (এর কোনো Closing Tag নেই)। 

<img src="images/du-logo.png" alt="DU Logo" width="100" height="100">
  • • src: ছবির ফাইল পাথ বা URL।
  • • alt: ছবি লোড না হলে যে বিকল্প লেখা (Alternate Text) দেখাবে।
  • • width / height: ছবির প্রস্থ ও উচ্চতা।

HTML Tables এবং Lists

HTML Table (টেবিল তৈরির নিয়ম)

  • <table> — টেবিল শুরু ও শেষ করে।
  • <caption> — টেবিলের শিরোনাম দেয়।
  • <tr> — Table Row (নতুন সারি তৈরি করে)।
  • <th> — Table Header (বোল্ড ও মাঝখানে থাকে)।
  • <td> — Table Data (সাধারণ ঘরের তথ্য)।
<table>

  <tr>

    <th>Dept</th>
  </tr>
  <tr>
    <td>Rahim</td>
    <td>Arabic</td>
  </tr>
</table>

index.htm (Dept of Arabic, DU)-এর গুরুত্বপূর্ণ অংশগুলোর ব্যাখ্যা

১. Internal CSS দিয়ে টেবিলের বর্ডার:

<style> table, th, td { border: 1px solid black; } </style>

এটি <head>-এর ভেতর থাকায় পুরো পেজের টেবিল এবং তার প্রতিটি ঘরের চারপাশে ১ পিক্সেল কালো বর্ডার তৈরি করেছে।

২. Inline CSS দিয়ে ব্যাকগ্রাউন্ড ও হেডিং স্টাইল:

<body style="background-color:powderblue;"> <h1 style="background-color:tomato; text-align:center; font-size:30px;">University of Dhaka, Dhaka-1000</h1>

পুরো পেজের ব্যাকগ্রাউন্ড হালকা নীল (powderblue), আর প্রথম হেডিংটি টমেটো লাল ব্যাকগ্রাউন্ডে মাঝখানে (center) ৩০ পিক্সেল সাইজে দেখানো হয়েছে।

৩. লোগো, ফরম্যাটিং, <pre> এবং <address>:

• <div style="text-align: center;"><img src="du_logo.jpg" ...></div> দিয়ে ঢাবি লোগো মাঝখানে রাখা হয়েছে।
• <pre> ট্যাগ দিয়ে "My Bonnie lies over the ocean" কবিতাটির ফাঁকা জায়গা ও লাইন ব্রেক হুবহু রাখা হয়েছে।
• <button onclick="alert('Hi! How are You?')"> দিয়ে ক্লিক করলে পপ-আপ মেসেজ দেখানোর JavaScript ইভেন্ট যুক্ত করা হয়েছে।

বিশেষ পর্যবেক্ষণ (Exam & Viva Tips):

শিক্ষকের ফাইলে <!--style="background-color:powderblue;"--> লাইনটি কমেন্ট করা আছে, তাই এটি ব্রাউজারে কাজ করবে না। এছাড়াও du_logo.jpg ছবিটি যদি HTML ফাইলের একই ফোল্ডারে না থাকে, তবে ছবির বদলে alt="DU Logo" লেখাটি দেখাবে!
